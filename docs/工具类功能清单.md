# ClawBot 工具类功能清单

> 项目：AI Agent 多工具并行开发  
> 盘点范围：`src/main/java/com/clawbot/wechatbot/tools` 及其 Spring 注册、调用配置  
> 代码快照：2026-07-24，Git 提交 `ac1d2db`  
> 盘点方式：基于当前工作区源码静态分析

## 1. 总体概览

当前项目共有 **8 个已注册的 Function Calling 工具**。所有工具均实现 `FunctionTool` 接口，并由 Spring 注入 `FunctionToolRegistry`，再通过 `DeepSeekChatService` 提供给大模型调用。

| 序号 | 工具调用名 | Java 入口类 | 核心功能 | 外部依赖 | 可用条件 |
|---|---|---|---|---|---|
| 1 | `get_current_time` | `CurrentTimeTool` | 查询指定时区的当前时间、星期和时间戳 | 无 | 始终可用 |
| 2 | `convert_currency` | `ExchangeRateTool` | 查询实时汇率并进行货币换算 | 聚合数据汇率 API | 需 `JUHE_EXCHANGE_API_KEY` |
| 3 | `calculate_bazi_fortune` | `BaziFortuneTool` | 计算四柱八字、五行、十神、纳音和流年关系 | `lunar` 1.7.7，本地计算 | 始终可用 |
| 4 | `get_weather` | `AmapWeatherTool` | 查询中国城市实时天气或天气预报 | 高德天气 API | 需 `AMAP_WEATHER_API_KEY` |
| 5 | `web_search` | `WebSearchTool` | 联网搜索实时信息和事实信息 | 博查 AI API、必应 HTML | 博查 Key 可选，必应作为兜底 |
| 6 | `get_news` | `TianNewsTool` | 查询最新综合新闻或关键词新闻 | 天行数据 API | 需 `TIANAPI_API_KEY` |
| 7 | `extract_web_page` | `WebPageExtractTool` | 抓取网页标题、描述和清理后的正文 | 目标网页 | 始终可用，但需要网络 |
| 8 | `check_url_safety` | `UrlSafetyChecker` | 基于规则检测 URL 风险并可展开短链 | 无；展开短链时访问网络 | 基础检测始终可用 |

## 2. 统一调用机制

### 2.1 `FunctionTool`

所有对外工具统一实现以下三个能力：

- `name()`：返回大模型调用时使用的唯一工具名。
- `definition()`：返回 OpenAI/DeepSeek Function Calling 格式的 JSON Schema。
- `execute(JsonNode arguments)`：执行模型传入的参数并返回文本结果。

### 2.2 `FunctionToolRegistry`

`FunctionToolRegistry` 负责：

- 按工具名注册全部 `FunctionTool` 实例。
- 汇总工具定义，构造发给模型的 `tools` 数组。
- 按名称查找并执行工具。
- 解析模型传入的 JSON 参数。
- 将未知工具、参数解析失败和执行异常统一包装为错误 JSON。

同名工具后注册时会覆盖先注册的实现。当前 Spring 配置通过 `List<FunctionTool>` 自动收集 8 个工具 Bean。

### 2.3 对话调用流程

`DeepSeekChatService` 将工具定义随对话请求一起发送给模型。模型返回一个或多个 `tool_calls` 后，服务逐个执行工具，将结果作为 `tool` 消息回传给模型，再由模型组织最终答复。

- 默认最大工具调用轮次：`3`
- 一轮中支持处理多个工具调用
- 超过轮次限制时终止并报错
- 工具成功结果和失败结果均以字符串形式回传给模型

## 3. 对外工具明细

### 3.1 当前时间工具

**工具调用名：** `get_current_time`  
**入口类：** `CurrentTimeTool`  
**实现方式：** Java `java.time` 本地计算，不访问外部网络。

**功能：**

- 获取精确到秒的当前时间。
- 支持 IANA 时区，例如 `Asia/Shanghai`、`UTC`、`America/New_York`。
- 支持默认时间、ISO-8601、中文时间、秒级时间戳和毫秒级时间戳。
- 支持自定义 `DateTimeFormatter` 格式。
- 同时返回星期、当年第几天、时区偏移和时间戳。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `timezone` | 否 | `Asia/Shanghai` | 标准时区 ID |
| `format` | 否 | `default` | `default`、`iso`、`chinese`、`timestamp_s`、`timestamp_ms` |
| `custom_pattern` | 否 | 空 | 自定义日期格式；设置后覆盖 `format` |

**主要输出：**

- `status`
- `timezone`
- `zone_display`
- `result`
- `weekday`
- `day_of_year`
- `timestamp_s`
- `timestamp_ms`

**限制与异常：**

- 无效时区返回错误结果。
- 无效自定义格式返回“格式化时间失败”。
- 时间以执行工具时的系统时钟为准。

### 3.2 汇率换算工具

**工具调用名：** `convert_currency`  
**入口类：** `ExchangeRateTool`  
**数据来源：** 聚合数据全球汇率接口。

**功能：**

- 查询两种货币之间的实时汇率。
- 按指定金额完成换算。
- 支持 ISO 4217 三位货币代码。
- 支持人民币、美元、欧元、日元、英镑、港币等常见中文别名。
- 支持 0 至 8 位结果精度。
- 源货币和目标货币相同时直接按汇率 `1` 返回，不访问外部接口。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `amount` | 否 | `1` | 待换算金额，不能小于 0 |
| `from_currency` | 是 | 无 | 源货币代码或常见中文名称 |
| `to_currency` | 是 | 无 | 目标货币代码或常见中文名称 |
| `precision` | 否 | `2` | 保留小数位数，范围 0 至 8 |

**主要输出：**

- 源货币、源金额和货币名称
- 目标货币、换算金额和货币名称
- 实时汇率
- 汇率更新时间
- “汇率仅供参考”的提示

**配置与限制：**

- 必须配置 `JUHE_EXCHANGE_API_KEY`。
- 默认接口：`https://op.juhe.cn/onebox/exchange/currency`
- 默认接口版本：`2`
- 默认连接超时 10 秒，请求超时 15 秒。
- 依赖上游接口返回目标方向的汇率记录。

### 3.3 八字流年工具

**工具调用名：** `calculate_bazi_fortune`  
**入口类：** `BaziFortuneTool`  
**实现方式：** 使用 `cn.6tail:lunar:1.7.7` 在本地完成历法和四柱计算。

**功能：**

- 支持公历和农历出生日期。
- 支持农历闰月。
- 计算年柱、月柱、日柱、时柱。
- 输出天干、地支、五行、纳音、天干十神和地支十神。
- 统计四柱表层五行数量。
- 输出生肖和日主。
- 分析指定流年的干支、五行及其与原局的六合、相冲、相害、自刑、天干五合和三合关系。
- 根据规则生成流年解释提示。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `birth_date` | 是 | 无 | `yyyy-MM-dd` |
| `birth_time` | 是 | 无 | `HH:mm` 或 `HH:mm:ss` |
| `calendar_type` | 否 | `SOLAR` | `SOLAR` 或 `LUNAR` |
| `leap_month` | 否 | `false` | 仅农历日期有效 |
| `timezone` | 否 | `Asia/Shanghai` | 第一版仅支持东八区 |
| `fortune_year` | 否 | 当前年份 | 支持 1900 至 2100 |

**主要输出：**

- 输入标准化结果
- 公历时间和农历时间
- 生肖、日主
- 四柱详细信息
- 五行表层计数
- 流年干支、五行、关系和解释提示
- 传统文化娱乐用途声明

**限制与异常：**

- 出生年份和流年年份仅支持 1900 至 2100。
- 第一版仅接受 `Asia/Shanghai`、`GMT+8`、`UTC+8` 或 `+08:00`。
- 公历日期不能设置 `leap_month=true`。
- 采用 `EightChar` Sect 2 规则处理晚子时日柱。
- 结果仅供传统文化和娱乐参考，不适用于重大决策。

### 3.4 高德天气工具

**工具调用名：** `get_weather`  
**入口类：** `AmapWeatherTool`  
**数据来源：** 高德开放平台天气查询接口。

**功能：**

- 查询中国城市、区县或 adcode 对应的实时天气。
- 查询未来天气预报。
- 保留高德返回的结构化数据，由大模型组织自然语言答复。
- 不会将 API Key 回传给模型。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `city` | 是 | 无 | 城市、区县名称或高德 adcode |
| `extensions` | 否 | `base` | `base` 为实时天气，`all` 为天气预报 |

**主要输出：**

- `success`
- `query_city`
- `type`
- 实时天气 `lives`，或天气预报 `forecasts`

**配置与限制：**

- 必须配置 `AMAP_WEATHER_API_KEY`。
- 默认接口：`https://restapi.amap.com/v3/weather/weatherInfo`
- 默认连接超时 10 秒，请求超时 15 秒。
- 非 `base`/`all` 的 `extensions` 会回退为 `base`。
- 主要面向高德天气服务覆盖的中国城市和区县。

### 3.5 联网搜索工具

**工具调用名：** `web_search`  
**入口类：** `WebSearchTool`

**功能：**

- 查询模型未知的事实信息和实时信息。
- 返回标题、摘要和链接。
- 使用双通道串行降级机制：
  1. 配置 Key 时优先调用博查 AI Web Search API。
  2. 博查未配置、异常或无结果时，回退到必应国内版 HTML 搜索。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `query` | 是 | 无 | 搜索关键词 |
| `count` | 否 | `5` | 返回条数，执行时限制在 1 至 20 |

**主要输出：**

- `success`
- `query`
- `result_count`
- `results[]`：每项包含 `title`、`snippet`、`url`

**配置与限制：**

- `BOCHA_API_KEY` 为可选配置；未配置时直接使用必应兜底。
- 默认博查接口：`https://api.bochaai.com/v1/web-search`
- 默认连接超时 30 秒，请求超时 60 秒。
- 必应通道依赖搜索结果 HTML 结构和正则解析，页面结构变化可能影响结果。
- 工具定义明确提示天气问题应优先使用 `get_weather`。

### 3.6 新闻查询工具

**工具调用名：** `get_news`  
**入口类：** `TianNewsTool`  
**数据来源：** 天行数据综合新闻接口。

**功能：**

- 获取最新综合新闻。
- 按关键词搜索新闻。
- 控制返回新闻条数。
- 将新闻标题、摘要、来源、时间和链接格式化为便于直接回复的文本。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `keyword` | 否 | 空 | 搜索关键词；为空时查询综合新闻 |
| `num` | 否 | `5` | 返回条数，执行时限制在 1 至 50 |

**主要输出：**

- 成功时返回逐条格式化的新闻文本。
- 失败时返回包含 `success=false` 和 `error` 的 JSON。

**配置与限制：**

- 成功调用必须配置有效的 `TIANAPI_API_KEY`。
- 固定接口：`https://apis.tianapi.com/generalnews/index`
- 默认连接超时 5 秒，请求超时 15 秒。
- `application.properties` 当前为环境变量配置保留了占位默认值；部署时仍需提供真实 Key。
- 成功返回格式与其他工具的结构化 JSON 风格不同。

### 3.7 网页正文提取工具

**工具调用名：** `extract_web_page`  
**入口类：** `WebPageExtractTool`  
**核心客户端：** `WebPageExtractClient`

**功能：**

- 请求指定网页并跟随常规重定向。
- 提取页面标题和 description/og:description。
- 删除脚本、样式、noscript、HTML 注释和标签。
- 规范空白并返回清理后的正文文本。
- 根据响应头中的 charset 解码网页。
- 按字符数截断正文，控制回传给模型的内容长度。
- 未提供协议时，客户端自动补充 `https://`。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `url` | 是 | 无 | HTTP 或 HTTPS 网页地址 |
| `max_body_chars` | 否 | 系统配置 | 最大正文字符数 |

**主要输出：**

- `success`
- 原始 `url` 和 `final_url`
- HTTP `status_code`
- `title`
- `description`
- `body_text`
- 失败时的 `error`

**配置与限制：**

- 默认连接超时 10 秒，请求超时 20 秒。
- 默认最大正文长度 6000 字符。
- 仅接受 HTTP/HTTPS。
- 仅处理文本、HTML 或 XML 类 Content-Type。
- 使用正则和基础实体解码，不执行 JavaScript，也不具备浏览器渲染能力。
- 对动态网页、登录页、反爬页面和复杂正文结构的提取效果有限。

### 3.8 URL 安全检测工具

**工具调用名：** `check_url_safety`  
**入口类：** `UrlSafetyChecker`

**功能：**

- 检查 URL 协议是否安全。
- 检测 HTTP 明文传输。
- 检测 IP 地址直连。
- 检测已知短链域名。
- 检测域名和路径中的可疑关键词。
- 检测非标准端口。
- 检测查询参数中的跳转、登录、验证等可疑字段。
- 可选展开短链，最多跟踪 5 次重定向。
- 按问题和警告数量计算风险分数，并分为安全、低风险、中等风险和高风险。

**输入参数：**

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `url` | 是 | 无 | 需要检查的完整 URL |
| `expand_short_link` | 否 | `false` | 是否展开已识别的短链 |

**主要输出：**

- URL、协议、主机、端口和路径
- `risk_level`
- `risk_score`
- `issues`
- `warnings`
- `positives`
- 展开后的 URL 和重定向次数
- 安全建议

**风险评分：**

- 每个高危问题计 20 分。
- 每个警告计 8 分，警告总分最多 40 分。
- 1 至 29 分为低风险，30 至 59 分为中等风险，60 分及以上为高风险。

**限制：**

- 这是本地启发式规则检测，不是恶意网址信誉库、病毒扫描器或反钓鱼认证服务。
- HTTPS 只表示传输加密，不代表网站内容可信。
- 短链展开使用 HEAD 请求，部分不支持 HEAD 的站点可能展开失败。
- 短链展开会产生额外网络访问。

## 6. 注册与提示词状态

8 个工具均已在 `BotBeanConfiguration` 中声明为 Spring Bean，并通过 `List<FunctionTool>` 自动注册。

系统提示词当前明确要求在以下场景强制调用专用工具：

- 天气：`get_weather`
- 汇率：`convert_currency`
- 八字和流年：`calculate_bazi_fortune`
- 新闻：`get_news`
- 网页内容：`extract_web_page`
- 当前时间：`get_current_time`

`web_search` 和 `check_url_safety` 已注册并会出现在工具定义列表中，但当前系统提示词没有单独列出这两个调用名；是否调用主要取决于各自工具描述和模型判断。
